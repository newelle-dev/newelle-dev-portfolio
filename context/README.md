## 🤖 Guidelines for AI Agents

When working on this repository:
1. **Developer Profile Accuracy:** Always refer to `developer-profile.md` for biographical details, contact links, and current status. Avoid inventing arbitrary job roles or social profiles.
2. **Design Language Integrity:** Follow `design-system.md` to uphold the dark-mode developer IDE theme, window chrome controls, and terminal accents.
3. **Component Conventions:** Consult `conventions.md` when authoring or refactoring React components in Next.js 16 (e.g., placing `"use client"`, leveraging `cn()` utility, and ensuring responsive mobile compatibility).
4. **Project Catalog Sync:** Update `projects.md` whenever adding or modifying projects in `lib/projects.ts` or `components/ProjectsSection.tsx`.
